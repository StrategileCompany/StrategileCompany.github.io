Política de Privacidade — Alice

Última atualização: 24 de outubro de 2026

A Alice é uma assistente pessoal (secretária) de uso privado, operada pela Strategile Company para um único usuário, Raphael Damas Mendes. Esta política descreve quais dados da conta Google conectada a Alice acessa, como usa e com quem compartilha.

A Alice não é um serviço aberto ao público: só a conta Google do próprio dono é conectada. Os dados acessados servem apenas para ele organizar e-mail e agenda, não são vendidos, não são usados para publicidade e não são compartilhados com terceiros além do necessário para o funcionamento descrito no item 5.

1. Quem somos

Raphael Damas Mendes (“Strategile Software”, Strategile Company), CNPJ 38.232.084/0001-61, controlador dos dados descritos aqui. Contato: strategilesoftware@gmail.com.

2. Dados do Google que a Alice acessa

  • Gmail (permissão gmail.modify): ler e buscar mensagens, aplicar e remover rótulos, arquivar e criar rascunhos. Nenhum e-mail é enviado sem a aprovação explícita do dono, mensagem a mensagem.
  • Google Agenda (permissão calendar): ler compromissos e criar, alterar ou remover compromissos a pedido do dono.
  • Endereço de e-mail da conta (openid, email): só para identificar qual conta está conectada.

3. Como os dados são usados

Exclusivamente para as tarefas que o dono pede ou autoriza: triagem e organização da caixa de entrada, rascunhos de resposta, resumo do dia, avisos de compromissos e ajustes na agenda. Os dados não são usados para publicidade, perfilamento de terceiros ou treinamento de modelos de IA de uso geral.

4. Onde ficam

A Alice roda em um servidor próprio da Strategile Company. O acesso ao Google é guardado como um token de autorização nesse servidor, protegido por login. Trechos de e-mails e compromissos podem ficar no histórico de conversa da assistente, visível apenas ao dono.

5. Com quem os dados são compartilhados

  • Provedores de modelo de IA (Anthropic e Google Gemini), apenas o trecho necessário para gerar cada resposta, transcrição ou áudio, nos termos de uso de API desses provedores.
  • Telegram, para entregar ao próprio dono avisos e rascunhos no chat privado dele com a assistente.

Não há venda, aluguel ou cessão de dados a qualquer outra parte.

6. Uso limitado (Google API Services User Data Policy)

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

7. Como revogar o acesso e apagar dados

  • Revogar a qualquer momento em myaccount.google.com/permissions (aplicativo “Secretária”/“Alice”), ou pelo botão “Apagar conexão” na configuração da assistente.
  • Para apagar o histórico guardado, escreva para strategilesoftware@gmail.com.

8. Alterações

Mudanças nesta política são publicadas nesta página, com a data no topo.
